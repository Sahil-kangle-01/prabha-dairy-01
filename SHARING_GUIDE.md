## 💬 Questions Your Client Might Ask

### Q: "How often does it sync from Tally?"
**A:** *"By default, manual sync using a button. We can also set it to auto-sync daily at 2 AM, or any schedule you prefer."*

### Q: "Can multiple people use it at the same time?"
**A:** *"Yes! It's a web application, so anyone on your network can access it simultaneously from their browser."*

### Q: "Will it change anything in Tally?"
**A:** *"No, it's completely read-only. It only reads data from Tally, never writes or modifies anything."*

### Q: "What if we add new suppliers/godowns in Tally?"
**A:** *"They'll automatically appear in the dashboard after the next sync. No manual configuration needed."*

### Q: "Can we access it on mobile?"
**A:** *"Yes! The dashboard is mobile-responsive. You can access it from phones and tablets too."*

### Q: "What reports can we generate?"
**A:** *"Currently: period summary, milk type breakdown, godown analysis, and supplier rankings. We can add more custom reports based on your needs."*

### Q: "How much data history can we see?"
**A:** *"All your historical data. You can select any date range from when you started using Tally."*

### Q: "Does it need internet?"
**A:** *"No, it works completely on your local network. Internet is only needed for initial setup."*
